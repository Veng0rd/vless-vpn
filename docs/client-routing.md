# Клиентская маршрутизация

## Что важно

Чтобы российские сервисы видели ваш реальный IP, клиент должен работать в `TUN` режиме. Если использовать только системный прокси без TUN, часть трафика и DNS может обходить правила split routing.

## Файлы в проекте

- [templates/v2rayn-routing-custom.json](../templates/v2rayn-routing-custom.json) — основной пресет `всё кроме РФ через VPN`
- [templates/xray-routing-snippet.json](../templates/xray-routing-snippet.json) — raw routing-snippet для клиентов, которые понимают обычный Xray JSON
- `output/rules/` — актуальные файлы `runetfreedom`, которые подтягиваются сервисом `rules-sync`

## Рекомендуемый сценарий для v2rayN / v2rayNG

1. Импортируйте `output/client/vless-uri.txt`.
2. Обновите geo-файлы в клиенте.
3. Включите `TUN`.
4. Добавьте кастомный routing preset из `templates/v2rayn-routing-custom.json`.
5. Убедитесь, что активен режим маршрутизации вида `всё кроме РФ через VPN`.

## Что даст этот пресет

- российские сервисы будут открываться напрямую
- зарубежные сайты и API пойдут через ваш VPS
- банки, Госуслуги, Яндекс и похожие сервисы не должны видеть IP сервера в Нидерландах

## Ограничения

- некоторые приложения кэшируют DNS и маршруты отдельно
- часть приложений может требовать отдельной проверки на утечки DNS/WebRTC
- для iOS, Shadowrocket, Hiddify, sing-box GUI и роутеров удобнее делать отдельный профиль под конкретный клиент

Когда скажете, каким именно клиентом вы пользуетесь на Windows/Android/iPhone/роутере, я подготовлю точный импортируемый профиль именно под него.
